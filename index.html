Core Architecture & Features

Designed for maximum compatibility, performance, and developer control.

Anti-Frame Block Removal

Strips restrictive `X-Frame-Options: DENY` and `Content-Security-Policy` headers server-side, enabling seamless embedding of external sites in sandboxed iframes.

Multi-Gateway Failover

Smart client-side rotation automatically switches proxy gateways in real time if any single edge region experiences rate limiting or downtime.

Logo & Asset Auto-Repair

Injects automatic image error handlers into proxied HTML pages to dynamically re-route broken logos and images through the proxy safely.

Header Customization

Full support for custom HTTP request headers, authorization tokens (`Bearer`), and custom CORS keys on all outgoing requests.

Console Bridge & Scriptlets

Features a cross-origin postMessage bridge that captures console logs (`log`, `warn`, `error`) from inside embedded sandboxed frames.

Cloudflare Pages Direct Root

How SCORS Works

Serverless Edge Request Flow & Header Sanitization Pipeline

1

Client Web App

Issues fetch request to `https://scorsbackup.pages.dev/?Url=https://api.target.com/data`

2

SCORS Edge Proxy

Cleans request headers, forwards request to target, strips `X-Frame-Options` & `CSP`, and injects `Access-Control-Allow-Origin: *`

3

Target Server Response

Target returns payload/HTML safely to client without CORS or iframe blocking restrictions.

Integration Code Examples

Easily integrate SCORS into any client application or programming language.

fetch('https://scorsbackup.pages.dev/?Url=' + encodeURIComponent('https://api.example.com/data'))
  .then(res => res.json())
  .then(data => console.log(data))
  .catch(err => console.error(err));

1-Click Deployment to Cloudflare Pages

Host your own dedicated SCORS instance on your GitHub repo (`z6sGD/SCORS`).

  1. 1
    Push to GitHub: Ensure your repository z6sGD/SCORS contains index.html and the functions/[[path]].js Cloudflare Pages route handler.
  2. 2
    Connect to Cloudflare: Go to Cloudflare Dashboard → Workers & Pages → Create Application → Pages.
  3. 3
    Select Repository & Deploy: Select z6sGD/SCORS, keep default build settings, and click Save and Deploy. Your proxy will be live at https://scorsbackup.pages.dev/!
